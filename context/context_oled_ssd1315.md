###### 模块信息:
名称: 0.96寸 SSD1315 OLED 显示模块
模块描述: 0.96寸 IIC OLED 白色单色显示模块，实际控制芯片为 SSD1315，分辨率 128x64。用于显示文字、状态信息、传感器数据、调试信息和简单图形。
模块类型: 执行器模块
功能标签: OLED显示、SSD1315、128x64、I2C、状态显示、调试显示
功能定义: 通过 I2C 向 SSD1315 写入命令和显存数据，驱动 OLED 面板显示 ASCII、少量内置中文字符、数值和简单图形。

###### 适用场景:
推荐应用: 设备状态显示、传感器数值显示、调试信息输出、小型人机交互界面、低功耗信息显示
不推荐应用: 大面积彩色图像显示、高刷新率动画显示、强阳光直射下的户外主显示、复杂高分辨率 UI、完整中文字体显示

###### 硬件能力:
核心芯片: SSD1315
关键参数: 0.96寸；128x64 分辨率；白色单色 OLED；Passive Matrix；1/64 Duty；默认 7-bit I2C 地址 0x3C；默认 I2C 速率 400kHz；3.3V 供电
通信: I2C，默认 7-bit 地址 0x3C，8-bit 写地址 0x78，默认速率 400kHz
控制: 支持初始化、清屏、显示开关、ASCII 绘制、少量内置中文绘制、无符号整数绘制、整屏 framebuffer 刷新
采集: 无；该模块不包含数据采集功能
输出: 128x64 单色白色 OLED 显示，Passive Matrix，1/64 Duty

###### 硬件接口:
接口类型: I2C
数量: 1
通信协议: I2C，默认 400kHz，可在长线或总线负载较大时降到 100kHz
工作模式:
 - 从机
引脚定义: GND、VCC/3V3、SCL、SDA
硬件地址：0x3C

###### 供电信息:
工作电压: 3.3V；OLED 资料中逻辑电压 VDD 为 1.65V~3.3V，模块原理图按 3V3 使用
电流需求: VDD 工作电流典型 180uA、最大 300uA；VBAT 内部 DC/DC 工作电流典型 25.6mA、最大 32mA
最大功耗: 约 107mW；实际功耗随亮度、点亮面积和刷新策略变化
供电注意事项: 原理图使用 3V3 供电；I2C_SCL / I2C_SDA 上拉到 3V3；所有互连设备需共地；ESP32-WROOM IO 为 3.3V，可直接匹配该模块 I2C 电平。

###### 系统资源占用:
GPIO占用: ESP32-WROOM 直连默认 SDA=GPIO21、SCL=GPIO22
通信资源占用:
I2C: I2C_NUM_0，400kHz，地址 0x3C
SPI: 无 SPI 占用
UART: 无 UART 占用
CAN: 无 CAN 占用
中断资源: 无中断资源占用
定时器资源: 若按例程周期刷新，使用 FreeRTOS 延时/任务调度资源
DMA需求: 无 DMA 需求

###### 使用限制:
硬件限制: 128x64 单色显示；固定画面长期高亮可能影响寿命；屏幕尺寸、连接器方向和排针形式需以实物为准
电气限制: 原理图含 4.7kΩ 上拉电阻、1uF / 2.2uF / 4.7uF / 100nF 等外围电容；供电和地线必须稳定
通信限制: 默认 I2C 400kHz；长线或总线负载较大时可能需要降到 100kHz；刷新整屏会占用 I2C 总线带宽
不兼容情况: 与同一 I2C 总线上地址相同且无法改址的模块不兼容
兼容性: 可连接模块: ESP32-WROOM I2C0 或其他 3.3V I2C 主控 - 推荐搭配主控: ESP32-WROOM-32E-N4 主板 - 推荐搭配模块: VL53L0X、MPU6050、按键模块、状态指示类模块 - 替代模块: SSD1306 OLED 模块、其他 128x64 I2C OLED 模块

###### 软件生态:
驱动支持: components_esp32wroom/oled_ssd1315_final
驱动依赖: bsp_i2c、ESP-IDF I2C master、显示 framebuffer、5x7 ASCII 字库、少量 16x16 中文字模
示例工程: examples_ch32/oled_direct_test0_final

###### 工程元数据:
成本区间: 6-10元
