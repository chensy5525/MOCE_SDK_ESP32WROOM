###### 模块信息:
名称: 四路舵机控制板
模块描述: 四路舵机控制板用于把主控或 CH32 输出的 PWM 控制信号分配到 4 个舵机接口，并为舵机提供独立 5V 电源输入。板上不包含专用舵机控制芯片，主要承担接口转接、供电汇流和接插件适配功能。适合 ESP32-WROOM 或 CH32 输出 4 路 50Hz PWM，控制 MG90S、MG995 等标准 PWM 舵机。
模块类型: 执行器扩展板
功能标签: 舵机驱动板、四路舵机、PWM分配、MG90S、MG995、5V供电、ESP32接口、CH32接口、机器人关节
功能定义: 接收来自 ESP32 或 CH32 的 4 路 PWM_A1~PWM_A4 控制信号，并将每一路信号连接到对应舵机的信号脚；通过独立 +5V/GND 电源接口为所有舵机供电，实现多路舵机角度控制。

###### 适用场景:
推荐应用: 四路舵机控制、机械臂多关节控制、机器人关节驱动、云台控制、小车转向和拨杆机构、MG90S/MG995 舵机实验、ESP32/CH32 PWM 舵机扩展。
不推荐应用: 带电流反馈的智能舵机控制、总线舵机控制、闭环位置反馈控制、大功率电机驱动、需要板上 PWM 生成芯片的场景、需要过流/过温保护的高可靠执行器系统。

###### 硬件能力:
核心芯片: 无专用控制芯片，板卡为无源/接口型四路舵机转接板。
关键参数: 4 路舵机接口；每路包含 GND、PWM 信号和 +5V；控制信号为 PWM_A1、PWM_A2、PWM_A3、PWM_A4；电源接口提供 +5V 和 GND；推荐使用 22AWG 杜邦线或足够载流能力的线材连接舵机电源；排针间距 2.54mm；CH32 接口排针间距 10mm。
通信: 单线 PWM 控制信号，不是 UART/I2C/SPI/CAN 通信设备。
控制: 由外部主控产生标准 RC Servo PWM，典型周期 20ms，频率 50Hz，脉宽一般为 1000us~2000us 或校准后的 500us~2500us。
采集: 无采集能力；不读取舵机角度、电流、温度或故障状态。
输出: 4 路舵机 PWM 信号转接和 5V/GND 供电分配。

###### 硬件接口:
接口类型: PWM
数量: 4 路舵机输出接口
通信协议: 标准 RC Servo PWM，约 50Hz，周期约 20ms。
工作模式:
 - PWM 信号转接
 - 舵机电源分配
引脚定义: 每路舵机接口包含 GND、PWM_Ax、+5V；电源接口包含 +5V、GND；ESP32/CH32 控制接口包含 PWM_A1、PWM_A2、PWM_A3、PWM_A4、GND。
硬件地址: 无
舵机接口定义:
 - H1: GND、PWM_A4、+5V
 - H2: GND、PWM_A3、+5V
 - H5: GND、PWM_A1、+5V
 - H6: GND、PWM_A2、+5V
ESP32接口: U1 接口包含 PWM_A1、PWM_A2、PWM_A3、PWM_A4、GND。
CH32接口: 预留 CH32 接口，排针间距 10mm，可将 CH32 的 4 路 PWM 输出接入 PWM_A1~PWM_A4 和 GND。
电源接口: CN1 提供 +5V 和 GND，用于舵机电源输入。

###### 供电信息:
工作电压: 舵机电源输入为 +5V，具体允许范围取决于所接舵机型号，例如 MG90S 通常 4.8V~6V，MG995 可工作于约 3V~7.2V。
电流需求: 取决于舵机数量、型号、负载和动作速度；4 路舵机同时启动或堵转时电流会明显升高，需要按峰值电流选择电源。
最大功耗: 由外接舵机决定；MG995 等大扭矩舵机同时工作时功耗和峰值电流远高于 MG90S。
供电注意事项: 舵机 +5V 不应由 ESP32 3.3V 引脚提供；建议使用独立 5V 大电流电源模块；ESP32/CH32 的 GND 必须与舵机电源 GND 共地；长线或大电流场景建议加粗电源线并在板端增加电解电容降低电压跌落。

###### 系统资源占用:
GPIO占用: 4 路 PWM 输出 GPIO，对应 PWM_A1~PWM_A4。
通信资源占用:
I2C: 无 I2C 占用。
SPI: 无 SPI 占用。
UART: 无 UART 占用。
CAN: 板卡本身不占用 CAN；若通过 CH32 servo gateway 接入 ESP32-WROOM，则 ESP32 与 CH32 之间占用 CAN/TWAI 通信。
中断资源: 无中断资源占用。
定时器资源: 需要外部主控提供 4 路 50Hz PWM；ESP32 直连时占用 LEDC 定时器/通道；CH32 控制时占用 CH32 定时器/PWM 资源。
DMA需求: 无 DMA 需求。

###### 使用限制:
硬件限制: 该板只是舵机接口/供电转接板，不会自动生成 PWM；必须由 ESP32 或 CH32 输出有效 PWM 信号；没有过流保护、角度反馈、电流检测或故障检测；舵机堵转可能导致电源跌落或发热。
电气限制: 舵机电源电流必须足够；控制信号和舵机电源必须共地；高电流舵机不应通过细线或面包板长距离供电；如果主控 PWM 引脚为输入专用引脚，则无法驱动舵机。
通信限制: PWM 信号无 ACK 和状态反馈；主控无法通过该板确认舵机是否到位。
数据限制: 舵机角度由 PWM 脉宽近似控制，真实角度受舵机型号、供电、负载、机械限位和校准参数影响。
不兼容情况: 需要总线协议舵机、智能舵机反馈、闭环位置控制、过流保护或大功率电机驱动的场景；ESP32-WROOM 的 GPIO34~GPIO39 等输入专用脚不能作为 PWM 输出使用。
兼容性: 可连接 ESP32-WROOM 可输出 PWM 的 GPIO，例如 PWMB1~PWMB4；也可连接 CH32 servo gateway 的 4 路 PWM 输出；兼容 MG90S、MG995 等标准三线 PWM 舵机。

###### 工程元数据:
成本区间: 低成本转接板，成本主要由接插件、PCB 和外接舵机决定。
优点: 接线简单、支持 4 路舵机、舵机电源与控制信号接口清晰、适合 ESP32/CH32 舵机实验和小型机器人结构。
缺点: 无保护电路、无反馈能力、不能生成 PWM、对外部电源能力依赖强、接线错误可能损坏舵机或主控。
