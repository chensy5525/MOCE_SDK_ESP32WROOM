###### 模块信息:
名称: MG995 180度大扭矩舵机模块
模块描述: MG995 是一款常见的大扭矩 180° PWM 舵机，内部集成直流电机、减速齿轮组、位置反馈电位器和控制电路。主控通过周期约 20ms 的 PWM 控制信号设置目标角度，舵机根据输入脉宽转动到指定位置。该型号相比 MG90S 体积更大、扭矩更高，适合中等负载机械臂、机器人关节、转向机构和较大力矩角度控制。
模块类型: 执行器模块
功能标签: MG995、舵机、180度、大扭矩、PWM、角度控制、机器人关节、机械臂、转向机构
功能定义: 通过 PWM 控制信号设置舵机目标角度，典型控制范围为 0°~180°；上层软件将角度值映射为脉宽，例如 0°≈500us/1000us、90°≈1500us、180°≈2500us/2000us，具体范围需结合实物舵机和机械限位校准。

###### 适用场景:
推荐应用: 中小型机械臂关节、机器人关节、大扭矩拨杆机构、小车转向机构、云台转向、门锁/挡板控制、教学实验、需要比 MG90S 更大力矩的角度定位场景。
不推荐应用: 高精度工业伺服控制、长时间堵转、连续旋转速度控制、低功耗电池设备、空间极小的结构、高可靠反馈控制、需要读取真实角度或电流反馈的场景。

###### 硬件能力:
核心芯片: MG995 舵机内部控制电路
关键参数: 180° PWM 舵机；工作电压 3V~7.2V；反应速度约 53~62 r/min；死区设定约 4us；工作电流标称约 100mA；工作扭力约 13kg/cm；高精度瓷齿/齿轮结构；空心杯电机；双滚珠轴承；线长约 25cm；外形尺寸约 54mm x 44mm x 40mm x 30mm，实际尺寸以实物为准。
通信: 单线 PWM 控制信号，不是 UART/I2C/SPI/CAN 通信设备。
控制: 通过 PWM 高电平脉宽控制目标角度；常用脉宽范围 500us~2500us 或 1000us~2000us；推荐先使用 1000us~2000us 保守范围，确认机械限位后再扩展到 500us~2500us。
采集: 无内置可读取数据接口；普通 MG995 不向主控反馈真实角度、电流、负载或故障状态。
输出: 舵机输出轴角度位置和较大扭矩。

###### 硬件接口:
接口类型: PWM
数量: 1 路 PWM 控制信号对应 1 个舵机
通信协议: 标准 RC Servo PWM，周期约 20ms，频率约 50Hz。
工作模式:
 - PWM 输入
 - 位置闭环输出
引脚定义: 棕色=GND/负极，红色=VCC/正极，橙色=PWM/SIGNAL 信号线
硬件地址: 无
控制信号定义: PWM 信号为 3.3V 或 5V 逻辑均常见可用；ESP32-WROOM 输出 3.3V PWM 通常可驱动信号脚，但必须与舵机电源共地。
典型脉宽: 0°=1000us、90°=1500us、180°=2000us；若实物支持更大行程，可校准为 0°=500us、90°=1500us、180°=2500us。
多路连接: 多个 MG995 同时工作时，每个舵机需要独立 PWM 信号线，并需要更大电流能力的独立供电；ESP32-WROOM 直连时可使用 PWMB1~PWMB4 等可输出 PWM 的 GPIO。

###### 供电信息:
工作电压: 3V~7.2V，常用 5V~6V 供电。
电流需求: 标称工作电流约 100mA，但启动、快速转动、负载较大或堵转时电流会显著高于标称值；多个 MG995 同时动作时需要按峰值电流预留电源余量。
最大功耗: 取决于供电电压、负载和堵转情况；堵转会造成大电流、发热、齿轮受力和系统电压跌落。
供电注意事项: 不建议使用 ESP32 板载 3.3V 给 MG995 供电；应使用独立 5V/6V 电源或足够电流能力的电源模块；舵机 GND 必须与 ESP32/CH32 GND 共地；建议在舵机电源端增加大容量电容以降低启动电流对主控的影响。

###### 系统资源占用:
GPIO占用: 每个 MG995 占用 1 个 PWM 输出 GPIO。
通信资源占用:
I2C: 无 I2C 占用。
SPI: 无 SPI 占用。
UART: 无 UART 占用。
CAN: 若通过 CH32 servo gateway 控制，则 ESP32-WROOM 侧占用 CAN/TWAI 网关通信资源；若 ESP32 直连舵机，则不占用 CAN。
中断资源: 无强制中断需求。
定时器资源: 需要 PWM/LEDC 定时器资源；ESP32-WROOM 直连时推荐使用 LEDC 50Hz PWM；CH32 控制时由 CH32 定时器/PWM 资源产生舵机信号。
DMA需求: 无 DMA 需求。

###### 使用限制:
硬件限制: MG995 不是连续旋转电机，不能作为普通电机控制速度；输出角度受机械限位影响；超出机械限位的脉宽可能导致堵转、发热或损坏齿轮；大扭矩工作时机械结构需要足够强度。
电气限制: 舵机供电电流必须足够；启动和堵转电流可能导致主控掉电复位；信号线必须与控制器共地；不要把舵机 VCC 接到 ESP32 3.3V 引脚。
通信限制: PWM 控制无 ACK、无真实角度反馈；主控只能发送目标角度，不能确认舵机是否实际到位。
数据限制: 角度映射需要按实物校准；不同批次 MG995 的死区、响应速度和实际角度范围可能存在差异；机械安装后建议限制最小/最大角度。
不兼容情况: 需要连续旋转速度控制的场景；需要位置反馈、电流反馈或故障反馈的高可靠场景；弱电源同时驱动多个 MG995；舵机大电流与主控供电共用且无隔离/滤波。
兼容性: 可由 ESP32-WROOM 直接输出 PWM 控制，也可由 CH32 servo gateway 通过 CAN 接收命令后在 CH32 侧输出 PWM；可搭配 Arduino、树莓派、STM32、ESP32 等学习开发板使用。
