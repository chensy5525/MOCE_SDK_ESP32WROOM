###### 模块信息:
名称: MG90S 金属齿轮微型舵机模块
模块描述: MG90S 是一款常见的小型 180° PWM 舵机，内部集成直流电机、减速齿轮组、位置反馈电位器和控制电路。主控通过周期约 20ms 的 PWM 控制信号设置目标角度，舵机根据脉宽自动闭环转动到指定位置。适合机器人关节、小车转向、机械臂夹爪、云台和轻载角度控制。
模块类型: 执行器模块
功能标签: MG90S、舵机、PWM、角度控制、180度、金属齿轮、机器人关节、云台、机械臂
功能定义: 通过 PWM 控制信号设置舵机目标角度，典型控制范围为 0°~180°；上层软件将角度值映射为脉宽，例如 0°≈500us/1000us、90°≈1500us、180°≈2500us/2000us，具体范围需根据实物舵机和机械结构校准。

###### 适用场景:
推荐应用: 小型机器人关节、机械臂夹爪、云台俯仰/转向、小车转向机构、门锁/挡板/拨杆控制、教学演示、轻载角度定位、简单动作机构。
不推荐应用: 大负载连续驱动、高精度工业伺服控制、长时间堵转、连续旋转速度控制、强冲击负载、需要编码器反馈的高可靠闭环位置控制。

###### 硬件能力:
核心芯片: MG90S 舵机内部控制电路
关键参数: 金属齿轮微型舵机；典型工作电压 4.8V~6V；典型角度范围 0°~180°；PWM 周期约 20ms；中位脉宽约 1500us；堵转电流可达到数百 mA 甚至更高；负载能力受供电、电压、机械臂长和舵机批次影响。
通信: 单线 PWM 控制信号，不是 UART/I2C/SPI/CAN 通信设备。
控制: 通过 PWM 高电平脉宽控制角度；常用脉宽范围 500us~2500us 或 1000us~2000us；推荐先使用较保守的 1000us~2000us，确认机械限位后再扩展。
采集: 无内置可读取数据接口；普通 MG90S 不向主控反馈真实角度、电流或故障状态。
输出: 舵机输出轴角度位置和扭矩。

###### 硬件接口:
接口类型: PWM
数量: 1 路 PWM 控制信号对应 1 个舵机
通信协议: 标准 RC Servo PWM，周期约 20ms，频率约 50Hz。
工作模式:
 - PWM 输入
 - 位置闭环输出
引脚定义: VCC/5V、GND、PWM/SIGNAL
硬件地址: 无
控制信号定义: PWM 信号为 3.3V 或 5V 逻辑均常见可用；ESP32-WROOM 输出 3.3V PWM 通常可直接驱动信号脚，但必须与舵机电源共地。
典型脉宽: 0°=1000us、90°=1500us、180°=2000us；若实物支持更大行程，可校准为 0°=500us、90°=1500us、180°=2500us。
多路连接: 4 路舵机需要 4 个独立 PWM 输出脚；例如 ESP32-WROOM 可使用 PWMB1~PWMB4 对应 GPIO32/GPIO33/GPIO25/GPIO26。

###### 供电信息:
工作电压: 4.8V~6V，常用 5V 供电。
电流需求: 空载运行通常为百 mA 级；启动、快速转动、负载较大或堵转时电流会明显升高；多路舵机同时动作时需要按峰值电流预留电源余量。
最大功耗: 取决于负载和堵转情况；堵转会显著发热并可能损坏舵机或拉低系统电压。
供电注意事项: 不建议直接使用 ESP32 板载 3.3V 给舵机供电；舵机 VCC 应使用独立 5V 电源或足够电流能力的 5V 电源模块；舵机 GND 必须与 ESP32/CH32 GND 共地；多路舵机建议在 5V 和 GND 间增加大容量电容以抑制启动电流导致的电压跌落。

###### 系统资源占用:
GPIO占用: 每路舵机占用 1 个 PWM 输出 GPIO；4 路舵机占用 4 个 PWM 输出 GPIO。
通信资源占用:
I2C: 无 I2C 占用。
SPI: 无 SPI 占用。
UART: 无 UART 占用。
CAN: 若通过 CH32 servo gateway 控制，则 ESP32-WROOM 侧占用 CAN/TWAI 网关通信资源；若 ESP32 直连舵机，则不占用 CAN。
中断资源: 无强制中断需求。
定时器资源: 需要 PWM/LEDC 定时器资源；ESP32-WROOM 直连时推荐使用 LEDC 50Hz PWM；CH32 控制时由 CH32 定时器/PWM 资源产生舵机信号。
DMA需求: 无 DMA 需求。

###### 使用限制:
硬件限制: MG90S 不是连续旋转电机，不能作为普通电机控制速度；输出角度受机械限位影响；超出机械限位的脉宽可能导致堵转、发热或损坏齿轮；负载过大时会抖动、掉电或无法到达目标角度。
电气限制: 舵机供电电流必须足够；舵机电源噪声可能导致 ESP32/CH32 复位；信号线必须与控制器共地；不要把舵机 VCC 接到 ESP32 3.3V 引脚。
通信限制: PWM 控制无 ACK、无真实角度反馈；主控只能发送目标角度，不能确认舵机是否实际到位。
数据限制: 角度映射需要按实物校准；不同批次 MG90S 的可用脉宽范围可能不同；建议在机械结构安装后限制最小/最大角度。
不兼容情况: 需要连续旋转速度控制的场景；需要位置反馈、电流反馈或故障反馈的高可靠场景；5V 舵机大电流与主控弱电源共用且无电源隔离/滤波。
兼容性: 可由 ESP32-WROOM 直接输出 PWM 控制，也可由 CH32 servo gateway 通过 CAN 接收命令后在 CH32 侧输出 PWM；推荐搭配电源模块、机械臂结构、云台结构、按键/语音/传感器触发模块使用。

###### 工程元数据:
成本区间: 8-20 RMB
优点: 成本低、体积小、控制简单、资料丰富、金属齿轮耐用性优于塑料齿轮、适合轻载角度控制。
缺点: 无位置反馈接口、无电流/故障反馈、精度和一致性有限、堵转电流大、长时间大负载易发热、供电设计要求高于普通小信号模块。
