###### 模块信息:
名称: ESP32 转接板
模块描述: ESP32 主板外设转接板，用于将主板上的 PWM_A、TXD1/RXD1、3V3/GND 网络转接到 GH1.25 和 2.54mm 排针接口，便于连接外设或调试。
模块类型: 转发模块
功能标签: ESP32转接、UART转接、3V3转接、GND转接、PWM_A网络、接口扩展
功能定义: 不包含 MCU 和主动通信逻辑，主要完成 ESP32 主板信号、电源和地线的物理转接。

###### 适用场景:
推荐应用: UART1 外设转接、3V3/GND 供电转接、输入信号/编码器信号转接、线束适配、开发调试
不推荐应用: 需要协议转换、信号隔离、电平转换、电源稳压、过流保护或主动控制逻辑的场景

###### 硬件能力:
核心芯片: 无；该模块不包含 MCU、传感器芯片或主动协议芯片
关键参数: 无 MCU；无主动协议转换；3.3V 信号直连；U1 GH1.25-5P 转接 PWM_A1~PWM_A4/GND；U2 GH1.25-4P 转接 TXD1/RXD1/3V3/GND
通信: UART 信号转接 TXD1/RXD1
控制: 无主动控制；PWM_A1、PWM_A2、PWM_A3、PWM_A4 为直连信号网络，按最终 board profile 对应 ESP32 引脚
采集: 无采集功能
输出: 无主动输出功能；仅物理转接 3V3、GND、TXD1、RXD1 和 PWM_A1~PWM_A4 信号

###### 硬件接口:
接口类型: GH1.25-5P、GH1.25-4P
数量: U1 GH1.25-5P 1 个；U2 GH1.25-4P 1 个
通信协议: UART 由主板 UART1 决定，默认 9600bps；PWM_A1~PWM_A4 为 GPIO 直连输入网络
工作模式:
 - 无主动主从角色，仅做信号直连转接
引脚定义: U1: PWM_A1、PWM_A2、PWM_A3、PWM_A4、GND；U2: TXD1、RXD1、3V3、GND
硬件地址：无硬件地址；该模块不包含可寻址器件

###### 供电信息:
工作电压: 3.3V
电流需求: 转接板自身无主动器件，静态电流近似 0mA；外接模块电流由 ESP32 主板 3V3 供电能力决定
最大功耗: 转接板自身近似 0W，不含外接负载和线损
供电注意事项: 转接板自身不稳压；3V3 来自主板；外接负载电流不得超过主板 3V3 供电能力；所有外设需共地；不得向 3V3 网络反灌电。

###### 系统资源占用:
GPIO占用: 不新增 GPIO，占用所转接的 ESP32 主板 PWM_A1~PWM_A4、TXD1、RXD1 信号；PWM_A1=GPIO36、PWM_A2=GPIO39、PWM_A3=GPIO34、PWM_A4=GPIO35；TXD1=GPIO17、RXD1=GPIO16
通信资源占用:
I2C: 无 I2C 占用
SPI: 无 SPI 占用
UART: UART1 TXD1/RXD1
CAN: 无 CAN 占用
中断资源: 无中断资源占用
定时器资源: 无定时器资源占用
DMA需求: 无 DMA 需求

###### 使用限制:
硬件限制: 该板仅做物理转接，不提供电平转换、隔离、保护或驱动放大；接口针序必须按实物和原理图确认
电气限制: 信号电平为 3.3V；外设不得向 3V3 网络反灌电；大电流负载不可直接从转接板 3V3 取电
通信限制: UART 波特率由 ESP32 主板固件决定，默认 9600；PWM_A1~A4 虽按网络名带 PWM，但对应 ESP32 输入专用脚，不能用于 LEDC PWM 输出
不兼容情况: 不适合连接 5V TTL 串口且无电平转换的模块；不适合直接驱动电机、舵机等大电流负载供电；不适合作为舵机 PWM 输出转接板
兼容性: 可连接模块: 3.3V UART 外设、输入/编码器类外设、调试线束 - 推荐搭配主控: ESP32-WROOM-32E-N4 主板 - 推荐搭配模块: 串口语音/通信模块、编码器输入模块 - 替代模块: 自定义线束或面包板转接

###### 软件生态:
驱动支持: 无独立驱动；使用 ESP32 主板对应 GPIO/UART 驱动
驱动依赖: bsp_uart、bsp_gpio；如作为编码器输入需结合业务驱动
示例工程: 无
