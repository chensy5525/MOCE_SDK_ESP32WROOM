###### 模块信息:
名称: VL53L0X 激光测距模块
模块描述: 基于 ST VL53L0X 的 ToF 激光测距传感器模块，通过 I2C 输出距离数据，可用于近距离测距、靠近检测、避障判断和距离显示。
模块类型: 传感器模块
功能标签: VL53L0X、ToF、激光测距、I2C、距离检测、靠近检测、避障
功能定义: 通过 I2C 初始化 VL53L0X、启动测距、轮询或中断获取测距完成状态，并读取距离值、原始距离值和测距结果状态。

###### 适用场景:
推荐应用: 近距离测距、用户接近判断、避障检测、物体存在检测、距离数据调试显示、机器人碰撞规避
不推荐应用: 未标定的高精度闭环控制、强环境光/强反射/黑色吸光材料目标场景、将单次测距结果作为安全决策唯一依据的场景

###### 硬件能力:
核心芯片: VL53L0X
关键参数: 940nm VCSEL；Class 1 激光；最大测距约 2m；工作电压 2.6V~3.5V；工作温度 -20~70°C；默认 7-bit I2C 地址 0x29；I2C 最高 400kHz；model ID 0xEE
通信: I2C，默认 7-bit 地址 0x29，数据手册 8-bit 地址标注为 0x52，最高 400kHz fast mode
控制: 支持初始化、探测地址、读取 model ID、启动单次测距、读取距离、读取状态
采集: 绝对距离数据，单位 mm
输出: distance_mm、raw_distance_mm、valid/out_of_range、测距状态、错误/超时状态

###### 硬件接口:
接口类型: I2C
数量: 1
通信协议: I2C，最高 400kHz fast mode
工作模式:
 - 从机
引脚定义: 3V3、GND、SCL、SDA
硬件地址：0x29

###### 供电信息:
工作电压: VL53L0X 数据手册 2.6V~3.5V；当前模块原理图按 3V3 供电
电流需求: Active ranging 平均典型 19mA；10Hz、33ms 测距序列平均最大约 20mA；VCSEL 峰值电流可达 40mA；硬件待机最大约 7uA，软件待机最大约 9uA
最大功耗: 平均约 66mW；峰值约 132mW
供电注意事项: 原理图使用 3V3 供电；SCL / SDA 上拉到 3V3；AVDDVCSEL、AVDD 与 GND 去耦电容需靠近芯片；所有互连设备需共地；XSHUT 若不由主控控制需通过上拉保持有效状态。

###### 系统资源占用:
GPIO占用: ESP32-WROOM 直连默认 SDA=GPIO21、SCL=GPIO22；
通信资源占用:
I2C: I2C_NUM_0，默认 400kHz，地址 0x29
SPI: 无 SPI 占用
UART: 无 UART 占用
CAN: 统一驱动可选 CH32 CAN-to-I2C 网关路径，ESP32 CAN 默认 TX=GPIO5、RX=GPIO4；直连例程不占用 CAN
中断资源: 当前直连驱动默认轮询，不占用中断资源
定时器资源: 当前统一例程 sampleintervalms 默认 500ms；直连读取包含测距 ready 轮询
DMA需求: 无 DMA 需求

###### 使用限制:
硬件限制: 标称最大测距约 2m；实际稳定范围受目标反射率、环境光、盖板串扰、安装角度和供电影响；需要工厂/应用侧 offset、crosstalk、温度相关校准才能获得更优性能
电气限制: 数据手册建议 400kHz、2.8V AVDD 时 I2C 上拉约 1.5kΩ~2kΩ；当前原理图含 R1/R2 10kΩ、R3/R4 2.4kΩ、C1 100nF、C3 4.7uF
通信限制: 多个 VL53L0X 默认同为 0x29，同总线多模块需要 XSHUT 控制和地址重新分配；长线或不稳定模块可将 I2C 从 400kHz 降到 100kHz
不兼容情况: 与同一 I2C 总线上地址相同且无法改址的模块不兼容；不适合未处理 OUT_OF_RANGE、MEASURE_TIMEOUT、COMM_FAIL 的安全关键判断
兼容性: 可连接模块: ESP32-WROOM I2C0、CH32 I2C 网关 - 推荐搭配主控: ESP32-WROOM-32E-N4 主板 - 推荐搭配模块: OLED 显示模块、蜂鸣器模块、运动控制模块 - 替代模块: VL53L1X 测距模块、其他 ToF 距离传感器模块
