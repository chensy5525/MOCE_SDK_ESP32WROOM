###### 模块信息:
名称: MPU6050 I2C 六轴姿态传感器模块
模块描述: 基于 InvenSense MPU6050 芯片的六轴运动传感器模块，集成三轴加速度计和三轴陀螺仪，通过 I2C 接口与主控通信，用于获取设备三轴加速度、角速度、温度以及姿态运动基础数据。当前原理图中 AD0 接地，因此默认 7-bit I2C 地址为 0x68。
模块类型: 传感器模块
功能标签: MPU6050、IMU、六轴传感器、加速度计、陀螺仪、温度检测、I2C、姿态检测、运动检测
功能定义: 通过 I2C 读取 MPU6050 内部寄存器，获取三轴加速度、三轴角速度和内部温度数据，并为倾斜检测、姿态估算、运动状态判断、振动检测等应用提供基础传感数据。

###### 适用场景:
推荐应用: 机器人姿态检测、平衡车控制、云台/舵机姿态反馈、无人机姿态采集、手持设备运动检测、IoT 运动传感设备、倾斜保护、运动触发控制、调试姿态数据显示。
不推荐应用: 高精度工业级姿态测量、长时间无校准惯性导航、绝对航向测量、磁北方向检测、高精度位置积分、强振动且无滤波补偿的闭环控制场景。

###### 硬件能力:
核心芯片: MPU6050
关键参数: 三轴加速度计；三轴陀螺仪；内部温度传感器；16-bit ADC；I2C 数字通信；加速度量程可配置为 ±2g / ±4g / ±8g / ±16g；陀螺仪量程可配置为 ±250 / ±500 / ±1000 / ±2000 dps；支持最高 400kHz I2C；默认地址 0x68。
通信: I2C，从机模式；当前原理图 AD0 接 GND，7-bit 地址为 0x68；若 AD0 拉高，地址可变为 0x69。
控制: 支持设备唤醒、采样率配置、低通滤波配置、加速度量程配置、陀螺仪量程配置、原始数据读取、温度读取、中断输出配置。
采集: 三轴加速度 ax/ay/az；三轴角速度 gx/gy/gz；内部温度 temp；可通过上层算法计算 pitch/roll 倾角。
输出: I2C 寄存器数据；典型输出单位可换算为 g、m/s2、dps 和摄氏度。

###### 硬件接口:
接口类型: I2C
数量: 1
通信协议: I2C，推荐 400kHz；长线或总线负载较大时可降为 100kHz。
工作模式:
 - 从机
引脚定义: 3V3、GND、SCL、SDA
硬件地址: 0x68
原理图连接: SDA/SCL 通过 10kΩ 上拉到 3V3；AD0 接 GND；VDD 和 VLOGIC 接 3V3；C2/C3/C4 为电源和 REGOUT 去耦电容；C1 为 CPOUT 电容。
连接器定义: H2 排针包含 3V3、GND、SCL、SDA；H1 为备用 2.54-1*4P 母座接口。

###### 供电信息:
工作电压: 3.3V
电流需求: 典型工作电流为 mA 级，实际电流随采样率、低功耗模式和内部功能配置变化。
最大功耗: 低功耗传感器模块级别，通常远低于电机、屏幕、语音等执行器模块。
供电注意事项: MPU6050 使用 3.3V 供电；I2C 上拉电阻接 3V3；ESP32-WROOM 和 CH32 均为 3.3V IO，可直接匹配；所有互连设备必须共地；电源纹波过大或地线不稳会导致读数抖动、I2C 通信失败或姿态漂移。

###### 系统资源占用:
GPIO占用: I2C SDA、I2C SCL；可选 INT 中断引脚。
通信资源占用:
I2C: 1 路 I2C 总线，默认地址 0x68。
SPI: 无 SPI 占用。
UART: 无 UART 占用。
CAN: 若通过 CH32 gateway 接入 ESP32-WROOM，则 ESP32 侧占用 CAN/TWAI 网关通信资源；MPU6050 本体不直接占用 CAN。
中断资源: 可选 INT 中断输出；基础轮询读取可不使用中断。
定时器资源: 周期采样时使用 FreeRTOS 延时/任务调度资源；姿态融合算法可能需要稳定采样周期。
DMA需求: 无强制 DMA 需求。

###### 使用限制:
硬件限制: MPU6050 不包含磁力计，不能单独提供绝对航向；加速度计和陀螺仪存在零偏和温漂；长时间姿态积分会产生漂移；安装方向会影响轴向定义，需要在软件中统一坐标系。
电气限制: 仅适合 3.3V I2C 电平；SDA/SCL 已通过 10kΩ 上拉到 3V3；I2C 总线过长、接触不良或多个模块地址冲突会导致扫描失败或读取异常。
通信限制: 默认 I2C 地址为 0x68；同一 I2C 总线上不能同时挂载另一个固定 0x68 且不可改地址的设备；400kHz 下线长和总线电容需受控。
数据限制: 原始加速度受重力分量影响；速度不能直接由单次加速度读数得到，长时间积分会快速累积误差；倾角建议用加速度和陀螺仪互补滤波或其他融合算法计算。
不兼容情况: 5V I2C 直连且无电平转换；同地址 I2C 设备冲突；强电机噪声与传感器共地不良；将 MPU6050 用作高精度定位或绝对航向传感器。
兼容性: 可连接 ESP32-WROOM I2C0、CH32 I2C gateway 或其他 3.3V I2C 主控；推荐搭配 OLED 显示模块、电机驱动模块、舵机控制模块、TOF 测距模块用于姿态显示和安全控制。
