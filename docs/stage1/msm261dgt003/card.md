## 3. 新版硬件连接

| 麦克风模块 U1 | 模块网络 | 新版转接板麦克风座 U2 | 主板网络 | ESP32 |
|---:|---|---:|---|---|
| 1 | 3.3V | 1 | 3V3 | 3.3 V 电源 |
| 2 | NC | 2 | I2S_WS | 模块端未连接，不由基础驱动使用 |
| 3 | SCK | 3 | I2S_SCK | GPIO18 / I2S0 PDM CLK |
| 4 | SD | 4 | I2S_SD | GPIO2 / I2S0 PDM DATA |
| 5 | GND | 5 | GND | 公共地 |

确认事项：

- SW2 将 U2 的 L/R 引脚切换到 3.3 V 或 GND。
- SW2 选择 3.3 V 时配置 right slot，选择 GND 时配置 left slot。
- C1=100 nF，跨接 U2 VDD 与 GND。
- 新版主板原理图将 GPIO18 标为 `I2S_SCK`、GPIO2 标为 `I2S_SD`。
- 当前仓库板卡文件仍同时把 GPIO18 定义为 `BOARD_SPI_SCK_GPIO`；I2S 与 SPI
  不能同时占用该引脚。这是软件资源冲突，不应在麦克风驱动中静默处理。
- GPIO2 属于启动绑带相关引脚，模块连接后的冷启动与下载模式必须实测。

## 4. 能力与范围

本阶段选择的最小能力：

- 通过 ESP32 I2S0 的 PDM RX 模式获取单声道 PCM 样本。
- 上层输出为有符号 16 位 PCM。
- API 只覆盖配置、初始化、启动、有限超时读取、停止和释放。
- 板级 I2S 资源、DMA 和 GPIO 生命周期归 BSP 所有。
- MSM261DGT003 层只负责器件允许范围、L/R 选择和 PDM 时钟约束。

明确不包含：

- 增益、滤波、自动增益、VAD、AEC、录音文件、播放；
- 标定声压级或音质指标；
- 产品音量阈值和业务状态机；
- CH32 转发、CAN 封装或桥接协议；
- 标准 I2S 音频编解码器的 TX/RX 扩展。

## 5. 可靠性 profile

profile: `continuous_input_bounded_read`

| 项目 | 冻结要求 |
|---|---|
| 资源所有权 | I2S0 RX 通道独占；GPIO18/GPIO2 生命周期由 BSP 管理 |
| 并发 | BSP 不内部序列化；一个任务或应用层互斥锁拥有完整生命周期 |
| 缓冲区 | 调用者提供容量明确的 `int16_t` 缓冲区；驱动检查空指针、容量和字节换算溢出 |
| 超时 | 所有读取有界；不得使用无限等待 |
| 状态 | 未初始化、未启动、重复初始化必须返回明确错误 |
| DMA | DMA 由 ESP-IDF I2S channel driver 管理；调用缓冲区在同步读取返回前保持有效 |
| 恢复 | 初始化中途失败必须释放已申请通道并记录清理失败；停止/释放错误不得吞掉 |

## 6. 身份确认与数据有效性

MSM261DGT003 没有在当前资料中确认可读的芯片 ID，因此不能用寄存器 ID 完成
身份确认。Stage 2/硬件验证采用分层证据：

1. 连接器线序、3.3 V 和共地正确；
2. GPIO18 出现配置目标对应的连续 PDM 时钟；
3. GPIO2 上存在随声学输入变化的 PDM 数据活动；
4. I2S DMA 在有限超时内返回非零数量的 16 位样本；
5. 安静与近距离发声时，峰值/平均绝对值出现可重复差异。

仅出现时钟或仅返回固定样本，均不得声明麦克风功能通过。

```text
transport=I2S0 PDM RX, CLK=GPIO18, DATA=GPIO2

```

Stage 2 编译验收：完整 ESP-IDF example 成功生成 ELF/BIN，编译警告为 0。

Stage 2 上板验收仍需用户单独授权烧录，并至少保留：电源读数、GPIO18 时钟
频率/占空比、GPIO2 数据活动、串口日志、冷启动/下载模式结果。没有这些证据时，
validation 只能标记为 `compile_passed` 或 `untested`。
